# AI 助理懶人包（agent-setup）

[English](README.en.md) ｜ 繁體中文

**一行指令，讓你的 Windows 電腦多一個會用 Telegram 跟你聊天、幫你做事的 AI 助理。**

這是給新手**試用、體驗**「擁有自己的 AI 助理」的懶人包：不用懂程式，回答幾個問題就裝好。它不是企業級產品，也沒有客服；請先看完下面的「風險與注意事項」再安裝。

---

## 它能做什麼

| 功能 | 說明 |
|---|---|
| 選你要的 AI | Claude Code、Codex（OpenAI）、Gemini（Antigravity）三選一，用你自己的帳號 |
| Telegram 遙控 | 出門在外用手機傳訊息給它；可以傳圖片、檔案、語音，它會回你 |
| 提醒與排程 | 「明天 8 點提醒我…」「每週一早上整理…」直接用講的 |
| 自動顧著 | 視窗被關掉會自己重開、電腦重開機後自動啟動 |
| 安全防護 | 擋下刪整個資料夾、格式化、讀密碼檔、關掉防護本身等危險動作；你在 Telegram 打 `/allow` 才放行一次 |
| 密碼庫 | 幫你登入網站時，AI 看不到密碼；每次都要你在 Telegram 按「允許」才會填 |
| 一鍵更新 | Telegram 打 `/update` 更新、`/還原` 退回上一版 |

## 需要準備

- Windows 10 或 11 電腦（要能上網）
- 一個 AI 帳號：Claude（Pro／Max）、ChatGPT（Plus 以上）或 Google 帳號，看你選哪個 AI
- Telegram（選用，不接也能在電腦上用）：安裝前先在 Telegram 找 @BotFather，傳 `/newbot` 照指示取名，就會拿到機器人的 token，安裝時貼上

## 安裝

1. 按 `Win` 鍵，輸入 `PowerShell`，打開「Windows PowerShell」
2. 貼上這一行，按 Enter：

```powershell
irm https://raw.githubusercontent.com/dead1786/agent-setup/main/bootstrap.ps1 | iex
```

3. 照畫面回答問題（用哪個 AI、取名字、個性、怎麼稱呼你、要不要接 Telegram），中途會請你登入 AI 帳號
4. 裝完會自動檢查一遍，最後看到總表全部通過就好了

## 日常使用

- **在電腦前**：直接在 AI 的視窗打字
- **用 Telegram**：傳訊息給你自己的機器人，它只聽你一個人的帳號

| Telegram 指令 | 做什麼 |
|---|---|
| `/status` | 看 AI 是不是在運作 |
| `/stop` | 中斷它正在做的事 |
| `/restart` | 重開 AI 視窗（接著之前的對話） |
| `/new` | 重開並開始新對話 |
| `/screen` | 把電腦畫面截圖傳給你 |
| `/allow` | 放行安全防護剛擋下的動作一次（10 分鐘內有效） |
| `/update`／`/還原` | 更新到最新版／退回上一版 |
| `/密碼` | 密碼庫：存帳密、看清單、刪除 |

## 移除

```powershell
irm https://raw.githubusercontent.com/dead1786/agent-setup/main/uninstall.ps1 | iex
```

只會移除這個懶人包裝的東西，被改過的設定照備份還原；AI 的記憶可以先備份到桌面。

## ⚠️ 風險與注意事項（請先看完）

1. **AI 會直接動手。** 它能看螢幕、點滑鼠、打字、讀寫檔案，不會每一步都問你。規則裡寫了「刪檔、花錢、替你對外發訊息之前要先問」，但 AI 可能會出錯，重要資料請自己備份。
2. **安全防護不是保險箱。** 它是看指令字面在擋，擋得住不小心和常見的手法；如果 AI 被網頁、信件、別人的程式裡藏的惡意指示騙了，還是有機會被繞過。**有人直接坐在你電腦前，它完全擋不住。**
3. **別讓 AI 讀來路不明的東西。** 陌生人寄信、留言叫你「讓你的 AI 去看我的專案／點這個連結」，最好不要。AI 規則裡已寫明：外部內容的指示只當資料，要先問你。
4. **Telegram 機器人的 token 等於鑰匙**，不要給任何人；`/screen` 會把整個螢幕傳到 Telegram，畫面上有機密時請留意。
5. **用量與費用**：AI 用的是你自己的帳號，用量和費用照你的方案算。排程、提醒、長時間工作都會吃額度。
6. **防毒軟體可能誤報**：這個工具會自動開視窗、送文字到視窗，少數防毒軟體會當成可疑程式。
7. **第三方服務的規則**：請遵守你使用的 AI 服務和 Telegram 的使用條款。
